# Team Brain History

Use this directory only when a material decision or handoff is superseded and the prior state would be useful for audit or reconstruction.

Do not copy every edit here. Git already preserves ordinary file history.

Create a snapshot only for meaningful transitions, for example:

- a major handoff between employee roles;
- a current decision being resolved or replaced;
- a material disagreement and its resolution;
- a module acceptance or rollback boundary.

Recommended filename:

`YYYY-MM-DD_<kind>_<short-name>.md`

Each snapshot should state what replaced it and why.
